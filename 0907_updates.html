3Findings

Retrieval from a lesson library carries no information. 12 random rubrics (78.2%) = 12 retrieved (79.4%, p=0.46) = the real-bug library (78.0%, p=1.0), all ≈ no library. Size, source (synthetic vs real bugs), on/off-policy — none of it matters.

Precision does, a little. Keeping only rubrics that fire on wrong mining patches and stay quiet on correct ones (78 of 191) gives the one library that beats no-library on the full 500 (400 vs 383, p=0.02); on Verified patches the kept rubrics fire 26% on wrong vs 15% on correct (unfiltered: 62% vs 74%).

Task-specific criteria generated from the issue beat every library (81.6%, p=0.0015 vs no library) — with an Opus judge and rich feedback.

The Opus gain is coaching, not evaluation. The identical judge and criteria with the agent shown only the reward scores 62.8% — indistinguishable from a Haiku judge (p=0.64) and 94 instances below the rich version. With a bare reward, 40% of agents submit while the judge still says "not fixed" (4% with explanations). A strong judge as a reward model is worth nothing; the +9pp over the interpreter is a stronger model explaining what is wrong with the patch.

Nothing works at the agent's own strength. Every Haiku-judge configuration sits 47–85 instances below the interpreter (false PASS on 35–42% of wrong patches, 2× the false alarms; withholding the PASSes changes nothing). The Haiku simulator says "pass" on 84% of the runs it gets wrong and the agent iterates on fiction.

4Issues, open

The side channel (found 13:00): an agent told "output withheld" redirects the run to a file and reads it. The two no-execution controls were invalid because of it; the environment is now closed (quarantine + classifier), the clean control is running, and every earlier arm has been audited.

No same-strength method yet. Judge, criticise-only judge, simulator, and reward-only strong judge all fail for the same reason: the agent can't act on a verdict it can't verify, and same-strength verdicts are wrong too often. Still running: the simulator handed the real exit code (sim-cond), and the titles-only bandwidth point.

What would count as success is now sharply defined: beat the clean noexec floor with a channel that is neither real execution nor a stronger model's prose.
