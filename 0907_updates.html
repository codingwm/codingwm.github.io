1Experiment setting

A Haiku 4.5 agent works in a repository by issuing bash commands. A classifier routes each command:

  • Reads, edits, navigation (cat, grep, sed, git diff, heredoc writes) → the real interpreter; the agent sees real output.
  • Code execution (pytest, python …, bash -c, ./script) → the command runs for its side effects, but its output is replaced by the coding world model (CWM): a model that reads the task, the agent's current diff and the command, grades the diff against a set of criteria, and returns the verdict. The agent sees that verdict plus the real return code.

Arms differ in who the CWM is (Haiku 4.5 or Opus 5) and which criteria it grades against (here: the 12 rubrics nearest to the task, retrieved from the 1000-rubric mined library, plus a standing task criterion). Two baselines bracket the CWM: the interpreter (real output for every command, 60 s cap) and no code execution (runs return nothing; reads and edits still work). An earlier configuration routed every command, reads included, through the CWM ("all-CWM").

Files written by a run are quarantined so the agent cannot read the output back; every trajectory is audited for leakage. No arm ever sees the hidden grading tests.

3Why bash-only beats all-CWM by 50 points

In the all-CWM configuration the CWM answered every command — cat, ls, grep, the result of an edit — with a rubric verdict on the current diff. The agent never saw a line of source: it could not find the file that implements the reported behaviour, could not check what an edit did, and typically submitted an empty or misplaced patch. Bash-only restores the code: the agent reads the implementation, reasons about the issue statically, edits, and re-reads its edit. On SWE-bench Verified that alone resolves 63.6%; real execution of its own probes adds the remaining 8.8 points. The trace pair below shows the same instance under both.

4Curation cost per rubric

On-policy real-bug mining (SWE-Gym → rubric library), from the 241-rollout realgym run. Prices: Opus 5 $5 / $25 per M tokens, Haiku 4.5 $1 / $5, GKE Spot ≈ $0.045 per node-hour.

Current = the pipeline as run. Cheap = the same pipeline, same models and labels, with three savings: mining rollouts capped at 150 agent steps instead of 250 (−20% on the agent and on the grades it triggers); the precision filter run with a Haiku pre-pass so Opus only judges (rubric, patch) pairs that plausibly apply, 64 rubrics per call, skipping pairs retrieval would never surface (−75% on the filter); and cached rollouts reused for any re-distillation or re-filter. Nothing about what is mined, how it is distilled, or how it is filtered changes.
